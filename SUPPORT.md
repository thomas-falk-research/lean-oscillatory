# Support

- **Which theorem do I need?** `docs/which-theorem.md`, then `docs/cookbook.md` and the examples under
  `examples/consumer/`.
- **My phase is not covered.** Open an issue with the template "My phase doesn't fit a statement".
- **A statement, a proof route or a record looks wrong.** Open an issue with the template "Error in a statement or
  a record". Give the label of the statement (for example `KL-F`), the file and line, and the smallest example.
- **Depending on OscInt from my project.** `docs/downstream.md`; versions and what is stable: `docs/policy.md`.
- **A way to make the checks pass when they should not.** `SECURITY.md`, privately.
- **Citing.** `README.md`, "How to cite"; `CITATION.cff`.

This is a one-person research project: answers come from the owner when time allows, and there is no paid support.
