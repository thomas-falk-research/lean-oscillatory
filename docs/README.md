# Documentation index

Start with the repository `README.md`. For a working session, read `lessons.md` (binding rules), then `HANDOFF.md`.
What is proved is in `STATUS.md` (derived from evidence); each statement's mathematics is in `statements.md`.

## Labels used throughout

The exact text and status of each label are in `statements.md` and `STATUS.md`.

- **S1.1–S1.3**: one-dimensional van der Corput bounds (first, second, third derivative), with amplitude.
- **S1.k**: the k-th derivative van der Corput bound.
- **S2.1**: non-stationary phase.
- **S2.2**: nondegenerate stationary phase, decay `m^{−1}`.
- **S3**: the uniform fold bound, `m^{−5/6}`.
- **S4.1, S4.1′**: the uniform D4 bound, `t^{−2/3}`.
- **S4.2–S4.4**: the D4 limit, the positivity of its constant, and the closed forms of the constant.
- **S5.1, S5.1′**: the uniform cusp (A3) bound, `t^{−3/4}`.
- **F1, F2**: the first front ends (`ContDiff` amplitudes; the D4 limit with its constant).
- **C1–C10, C7′**: conversions from textbook notation (derivatives, Hessians, discriminants, norms, support).
- **FE-…**: front ends restating S2–S4 for users. **…L** and **…l**: their local-smoothness forms.
- **S2.2F, S3c**: the compact-family forms of S2.2 and S3.
- **GD-C, GD, GD-F, GD-N**: global decay from a pointwise classification.
- **SH**: sharpness.
- **T1**: torus unfolding.
- **T6, T6L**: the 2D lattice-Laplacian dispersive bound and its leading term.
- **T0E, T6F, T6E** (batch LE): explicit lattice constants.
- **GD-…-V** (batch VT): the global decay estimates for amplitudes in a Banach space.
- **Batch labels:** **API1–API3** are the front-end batches; **GD, LE, VT, A3** are the batches named after their
  statements.
