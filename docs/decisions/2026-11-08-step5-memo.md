### (i) Adopt a general test-layer exception (the referee's corrected text), plus the same waiver
For the case where you want a path, not only a waiver. Exact text: §F.1 of `review/2026-11-08-step5-rule-referee.md`

A new statement file with the same ten statements, each hypothesis a named `def` shared with its sanity theorem and

## 4. Recommendation
**(iii).** The conditional form and def-bundling cover different plants: the conditional form tests the frozen text
for plants that make a hypothesis harder to discharge; def-bundling with bite instances also tests plants that weaken
a hypothesis; (ii) would add the latter for API3 but cannot restore the order claim. Both referees judged every
statement faithful before and after the proofs, so the residual risk is the weakening class named in the waiver,
which (ii) would close at the cost of half a session. A general exception (i) is not needed once step 2 says what
lessons 33 says. If you weigh the weakening class higher than the cost, choose (ii).
