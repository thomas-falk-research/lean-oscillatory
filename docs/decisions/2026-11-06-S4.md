# Decisions on the three open S4 questions (2026-11-06)

The owner delegated the three decisions ("choose the best … after verifying and validating"). Each decision below
states the options, the evidence, the choice, and what would make us revisit it. Labels as in `docs/lessons.md`.

## 1. How to define the S4.2 constant c_C

Options.
- (a) Closed form in the statement, c_C := Γ(1/3)²/(√3|Disc|^{1/6}). Then "c_C ≠ 0" is trivial (Γ > 0), so the
  brief's requested alternating-series argument would prove nothing, and the limit itself needs the special-function
  evaluation ∫₀^∞ cos u u^{−1/3} du = Γ(2/3)/2 and a Beta-integral evaluation of J(C) inside the analytic proof.
- (b) Gamma-free definition c_C := (1/3)·I·J(C) with I = ∫₀^∞ cos u u^{−1/3} du (improper) and
  J(C) = ∫₀^{2π} |C(cos θ, sin θ)|^{−2/3} dθ, and three separate statements: S4.2 the limit, S4.3 positivity (the
  brief's alternating series, no Gamma), S4.4 the closed forms.
- (c) c_C := the limit itself (lim t^{2/3} ∫ e^{itC}·χ for a fixed cut-off χ). Rejected: S4.2 would become nearly
  tautological and S4.3/S4.4 would have to re-derive the polar formula anyway.

Choice: (b). Reasons: it is what the brief asks for (c_C ≠ 0 *by the alternating series, not by Gamma*); it keeps
the analysis (S4.2), the positivity (S4.3) and the special-function identity (S4.4) independent, so each can be
proved, reviewed and cited on its own; the defining formula is the one the proof produces (polar coordinates), so
S4.2 carries no special-function work; S4.2 + S4.4 together are the brief's limit with its constant.

Evidence.
- PROVEN (on paper, `docs/statements.md` S4): ∫₀^∞ e^{isr³} r dr = (1/3)|s|^{−2/3}∫₀^∞ e^{±iu}u^{−1/3}du and
  C(−z) = −C(z) give c_C = I·J/3 (real). J(C) < ∞ iff Disc C ≠ 0. Under C ↦ λ·C∘L both sides of the closed forms
  scale by |λ|^{−2/3}|det L|^{−1}, and every real cubic with Disc < 0 (> 0) is of this form for x³ + y³
  (x³ − 3xy²); with I = Γ(2/3)cos(π/3) = Γ(2/3)/2 this gives c = Γ(1/3)²/3 for x³ + y³ (Beta integral) and
  c = √π Γ(1/6)/3 = Γ(1/3)²/108^{1/6} for x³ − 3xy² (via Γ(1/6) = 2^{−1/3}(3/π)^{1/2}Γ(1/3)²).
- VALIDATED (`numerics/src/bin/d4const.rs`, output `numerics/results-d4const-2026-11-06.txt`; binary64,
  tanh-sinh quadrature split at the roots, Lanczos Γ checked against √π and Γ(1/3) to 3e-16):
  I = Γ(2/3)/2 to 6e-15; the alternating structure (a₀ = 1.4711, a₁ = −1.3810, a₂ = 1.0868, a₃ = −0.9479, |aₖ|
  decreasing for k ≤ 60, a₀ + a₁ = 0.0901 > 0); I·J/3 equals the closed form to ≤ 8e-15 relative for eight cubics
  (four with Disc < 0, four with Disc > 0, including generic coefficients); direct 2D quadrature of
  t^{2/3}∫∫e^{itC}A at t ≤ 300 extrapolates to c_C A(0) within 3.6e-4 (x³ + y³) and 1.2e-6 (x³ − 3xy²).
- Mathlib at the pin has `Real.Gamma`, the Beta integral (`Complex.betaIntegral_eq_Gamma_mul_div`), reflection
  and duplication (`Real.Gamma_mul_Gamma_one_sub`, `Real.Gamma_mul_Gamma_add_half`) and
  `integral_cpow_mul_exp_neg_mul_Ioi`, so S4.4 is provable with existing API plus an Abel-limit argument for the
  cosine moment; no Mellin transform of cos is needed.
- Prior art: the polar/Mellin evaluation of homogeneous oscillatory integrals is classical (Duistermaat 1974,
  Arnold–Gusein-Zade–Varchenko vol. II); the elliptic-umbilic constant in this form was not found in a quick search
  (PLAUSIBLE known; no novelty claimed).

Revisit if: a referee shows the Gamma-free definition differs from the brief's intent; or Mathlib gains a
`mellin cos` lemma (S4.4 would shorten, nothing else changes).

## 2. Widen S4.1 from `disc < 0` to `disc ≠ 0`

Options: keep `disc < 0` only; edit S4.1 (forbidden: stamped statements are never edited); add S4.1′ with
`disc ≠ 0` as a new frozen statement next to S4.1.

Choice: add S4.1′ (`D4BoundNeStatement`) and state S4.2–S4.4 for `disc ≠ 0`, with sign-specific closed forms; keep
S4.1 unchanged as the brief's case. Reasons: the brief's first condition, "C has an isolated critical point", is
exactly `disc ≠ 0`; its "negative discriminant" was added "(needed for c_C)", i.e. for the closed form, and the
Gamma-free c_C and the second closed form remove that need; the classical t^{−2/3} theorem is for both umbilics;
the proof of S4.1 already uses only `disc ≠ 0` (`CubicGaugeFacts`), so S4.1′ reuses every part; S4.1 stays as
stamped, so nothing already reviewed changes. Cost: a new statement, stamp, two blind reviews, and an assembly
variant of `d4Bound_of` with `hdisc : disc ≠ 0`.

Evidence: VALIDATED as above (closed form and limit for Disc > 0); `OscInt/D4/LimitSanity.lean` shows the
elliptic umbilic meets the new hypotheses.

## 3. Build the nanoda checker from source

Facts (checked 2026-11-06): upstream is `github.com/ammkrn/nanoda_lib` (the old `nanoda` repository is
deprecated); HEAD is `8de7e0c4ed3052745a7f8725164efd9e76d84c56` (2026-10-29), crate `nanoda_lib` 0.4.31, Apache-2.0,
binary `nanoda_bin`, `Cargo.lock` with 29 crates from crates.io (checksummed). The checker we run today is the
`nanoda_bin` 0.4.19 bundled in the Lean toolchain archive, so it shares that archive's supply chain with four other
checkers. A Zulip report (Dec 2025) mentions a panic on the default branch fixed on `debug`; a newer version is a
second implementation-version, not only a second build.

Options: (a) keep only the bundled binary; (b) build locally in this session (refused by the session's safety
classifier on 2026-11-05; not worked around); (c) build in CI on a fresh GitHub runner from the pinned commit with
`cargo build --release --locked` on a pinned Rust toolchain, and run it on the same export as an additional,
required checker.

Choice: (c). Reasons: independent supply chain (source at a pinned commit plus checksummed crates, compiled on a
clean runner each push) for one of the six export kernels; reproducible and visible to anyone reading CI; no
local execution of third-party build scripts. The bundled 0.4.19 stays in `make lean-replay`, so local results do
not change. Acceptance is the checker's own success line, never its exit status (lesson 2). If the from-source
checker rejects what the bundled one accepts, CI fails and the disagreement is investigated before any claim.
