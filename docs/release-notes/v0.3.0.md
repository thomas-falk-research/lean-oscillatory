# OscInt v0.3.0 — release notes

The first release with a stable surface for downstream projects (`docs/policy.md`): the entry point
`import OscInt.API`, the machine-readable statement list `stamps/statements.json`, and the downstream checker
`tools/oscint_check.py`. Toolchain `leanprover/lean4:v4.35.0`, Mathlib `56a005855ea17e0b0958f73ec801ae140b0a1679`.

CI job `release-pin` (`tools/check_release_pin.sh`) recomputes both at the tag and fails if this table disagrees.
Downstream projects use them as in README, "Depending on OscInt":

```toml
[[require]]
name = "oscint"
git = "https://github.com/thomas-falk-research/lean-oscillatory"
rev = "v0.3.0"
```

```bash
python3 .lake/packages/oscint/tools/oscint_check.py --statement <statement> \
  --expect-sha256 44aacc38d4d16cc8a7b514acc67c12a19ac8ca78f92123e46bb1e3d7cd641f77
```

Against tampering (README), keep your own copy of `tools/oscint_check.py` whose SHA-256 equals the one above, and
pin the tag's commit hash instead of the tag name.

## Statement changes

None to an existing statement (CHANGELOG "v0.3.0", "Statement changes"): the eleven statements of v0.2.0 keep their
files and commitments. Added: F1 `AmpBoundOfContDiffStatement`, F2 `D4LimitClosedFormStatement`. Newly proved: S4.4,
F1, F2. Thirteen statements in all, every one machine-checked as stated (`docs/STATUS.md`; F1 and F2 without the
"statement fixed before the proof" claim).

## Publishing (owner)

1. Tag the release commit named in `docs/HANDOFF.md` ("Release v0.3.0"): on GitHub, Releases → Draft a new release →
   Choose a tag → type `v0.3.0` → Target: that commit (Recent commits, or the branch whose head it is) → title
   `OscInt v0.3.0` → paste this file from "The first release…" to the end of "Evidence" → Publish release.
2. Zenodo mints the version DOI. Add it to `CITATION.cff` (`identifiers:`, "Version 0.3.0") and to README's citation
   line in a follow-up commit.
3. CI job `release-pin` turns green on the next run (re-run it from the Actions tab, or push any commit), and
   `consumer-release` builds a project that requires OscInt by this tag.
