# S4.1 proof route (uniform D4 bound)

Statement: `OscInt.Statements.D4BoundStatement` (`docs/statements.md`, S4.1). Blueprint parts: `Blueprint/D4.lean`
(D1–D9). Assembly: `OscInt.D4.d4Bound_of` in `OscInt/D4/Assembly.lean`, checked by Lean against the parts as
hypotheses. Prior art: the dyadic-rescaling proof of the t^{-2/3} decay at a D4 point is standard (Duistermaat,
"Oscillatory integrals, Lagrange immersions and unfolding of singularities", CPAM 27 (1974); Varchenko's Newton
polyhedra bounds; Stein, *Harmonic Analysis* (1993), ch. VIII); the version here is a direct reduction to S3 and S2.1
(this repository).

Notation: max norm on ℝ², ‖·‖; B̄(0, r) the closed max-norm ball; annulus 𝒜 = {1/2 ≤ ‖z‖ ≤ 2}.

## Step 1. Normalisation (D1)
ψ := φ − φ(0) − Dφ(0). Then ψ is C⁴, ψ(0) = 0, Dψ(0) = 0, and second and third derivatives of ψ and φ coincide
everywhere (an affine function has zero second derivative), so `cubicCoeffs ψ = cubicCoeffs φ` and D²ψ(0) = 0.
Pointwise tφ(κ) + y·κ = tφ(0) + tψ(κ) + y'·κ with y' = y + t∇φ(0), so the integrals differ by the unimodular
factor e^{itφ(0)}. The bound for ψ uniform in y' ∈ ℝ² gives the bound for φ uniform in y.

## Step 2. Rescaled family (D2)
Ψ_ε(z) = ε⁻³ψ(εz) for ε ≠ 0, Ψ_0 = C (the cubic part, `cubicPoly (cubicCoeffs ψ)`). Claim: (ε, z) ↦ D^j_zΨ_ε(z)
is continuous on ℝ × ℝ² for j ≤ 4. For ε ≠ 0, D^jΨ_ε(z) = ε^{j−3} D^jψ(εz). By Taylor's formula with integral
remainder, using ψ(0) = Dψ(0) = D²ψ(0) = 0:
- j = 4: ε D⁴ψ(εz) → 0 = D⁴C;
- j = 3: D³ψ(εz) → D³ψ(0) = D³C (symmetry of D³ψ(0) identifies the trilinear form with the polynomial C);
- j = 2: ε⁻¹D²ψ(εz) = ∫₀¹ D³ψ(sεz)[z, ·, ·] ds → D³ψ(0)[z, ·, ·] = D²C(z);
- j = 1, 0 likewise with ∫₀¹ (1−s) … and ∫₀¹ (1−s)²/2 ….
Each integrand is jointly continuous in (s, ε, z), so the limits are locally uniform in z. ✔ standard.

## Step 3. The gauge (D3, D4, D5)
For a C³ function Ψ at k let H = D²Ψ(k) with entries p = ∂₁₁, r = ∂₁₂, s = ∂₂₂, T = D³Ψ(k). Put v₁ = (−r, p),
v₂ = (s, −r); Hv₁ = (0, ps − r²), Hv₂ = (ps − r², 0), so both lie in ker H when det H = 0.
Gauge g = (det H)² + T[v₁³]² + T[v₂³]², and h = p² + r² + s².
- (D4) g > 0 and h > 0 ⇒ FoldOrNondeg: if det H ≠ 0 done; otherwise H ≠ 0 (h > 0) has rank one, its kernel is a
  line, some T[v_i³] ≠ 0 forces v_i ≠ 0, so v_i spans the kernel; any kernel vector v ≠ 0 is λv_i with λ ≠ 0 and
  T[v³] = λ³T[v_i³] ≠ 0.
- (D3) For a binary cubic C with Disc ≠ 0 and z ≠ 0: h(z) > 0 and g(z) > 0. Proof. T is the constant symmetric
  tensor of C, H(z) = T[z, ·, ·]. If H(z) = 0, then in a basis (z, w) all coefficients of T with an index z vanish,
  so C is a multiple of the cube of a linear form, Disc = 0. If det H(z) = 0 and T[u³] = 0 for the kernel vector u:
  if u ∥ z then T[z, z, ·] = 0, i.e. ∇C(z) = 0 at z ≠ 0, a repeated root (Euler), Disc = 0; otherwise in the basis
  (z, u) the only nonzero coefficient of T is T[z³], C is a cube of a linear form, Disc = 0. The proof in Lean may
  instead use polynomial certificates (Disc · z₁^N and Disc · z₂^N in the ideal generated by the vanishing
  conditions). Checked numerically before the proof (20 000 random (q, z), no gauge or Hessian norm below 10⁻¹²; a
  throw-away script, not part of the record; the Lean proof is the record).
- (D5) g and h are continuous functions of D²Ψ_σ(k), D³Ψ_σ(k), hence jointly continuous in (σ, k) for a C³ family;
  {g > 0, h > 0} is open and contains {σ₀} × K, K compact, so it contains U × K for a neighbourhood U (tube lemma).
Applied at ε = 0 on 𝒜 (which excludes 0): there is ε₀ ∈ (0, 1] with FoldOrNondeg(Ψ_ε) on 𝒜 for all ε ∈ [0, ε₀].

## Step 4. Dyadic decomposition and rescaling (D6–D8, F1c, F1d, F2b)
χ smooth, χ = 1 on B̄(0, 1), tsupport χ ⊆ B̄(0, 2), 0 ≤ χ ≤ 1, χ(2z) ≤ χ(z) (D7); β = χ − χ(2·) ∈ [0, 1],
tsupport β ⊆ 𝒜. With ε_j = ε₀/2ʲ: χ(κ/ε_J) + Σ_{j<J} β(κ/ε_j) = χ(κ/ε₀) = 1 on B̄(0, ε₀) (telescoping, since
2/ε_j = 1/ε_{j+1}). δ := ε₀ in the statement.
- Inner piece: amplitude ≤ M, support in B̄(0, 2ε_J): |·| ≤ 4(2ε_J)²M = 16ε_J²M (D8).
- Piece j < J: κ = ε z (F1c, |det| = ε²): ε² I(m(Ψ_ε + p·), β·A(ε·)) with m = tε³ ≥ 1, p = y'/(tε²). The amplitude
  β·A(ε·) has bound (2, 𝒜, C_β M) (F1d with ‖ε·id‖ ≤ 1, then F2b). If ‖p‖ ≤ G, S3 on (Λ = [0, ε₀], 𝒜, B̄(0, G))
  gives C₃ C_β M m^{−5/6}; if ‖p‖ > G, then |∇(Ψ_ε + p·)| ≥ 1 on 𝒜 (D6: G − sup‖DΨ‖ chosen ≥ 1), and S2.1 with
  N = 1 gives C₁ C_β M m^{−1} ≤ C₁ C_β M m^{−5/6}.

## Step 5. Summation (D9)
J := least j with tε_j³ < 1. Then ε_J² ≤ t^{−2/3} and, with ε_{J−1} ≥ t^{−1/3},
Σ_{j<J} ε_j²(tε_j³)^{−5/6} = t^{−5/6} Σ_{j<J} ε_j^{−1/2} ≤ t^{−5/6} ε_{J−1}^{−1/2}/(1 − 2^{−1/2}) ≤ 3.42 t^{−2/3}.
Total: |I| ≤ (16 + 4 D C_β) M t^{−2/3}, D = max(C₃, C₁, 0). ∎

Constants: C depends on φ through ε₀ (the gauge margin, which degenerates as Disc → 0), G, C₃, C₁; this is allowed
(φ is fixed before ∃ δ C). Only `disc ≠ 0` is used (D3), so the same route proves the D4⁻ case.
