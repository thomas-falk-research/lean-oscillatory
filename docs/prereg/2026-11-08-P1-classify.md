# Pre-registration: numeric classification of the critical-point types of two dispersion relations (P1)

Registered 2026-11-08 (session 6), before the program `numerics/src/bin/classify.rs` has been run and before any Lean
statement of the global-decay batch (GD) exists. Numerics are tooling, never evidence for a Lean theorem (README).
Purpose: decide, before freezing, whether the planned hypothesis of the global-decay statements ("every point of the
compact set is nondegenerate or a fold, except finitely many D4 points with nonzero discriminant") holds for the two
acceptance phases, and so whether the acceptance examples are feasible. Changing the protocol after the run is a new
registration with its own date; the first run's output is kept.

## Phases (fixed now)
- L: the 2D lattice Laplacian symbol ω(x, y) = cos x + cos y on the torus [−π, π)².
- Aσ: the arccos dispersion relation Ψσ(x, y) = arccos(a cos x + b cos y), σ = (a, b), for the parameter values
  σ ∈ {(0.5, 0.3), (0.45, 0.45), (0.2, 0.7), (−0.3, 0.6), (0.6, −0.35), (0.05, 0.9)} (all with |a| + |b| < 1).

## Classification (definitions fixed now)
At a point k with Hessian H = D²Ψ(k) and third derivative T = D³Ψ(k) (exact closed-form derivatives, f64):
- N (nondegenerate): det H ≠ 0;
- F (fold): rank H = 1 and T[v, v, v] ≠ 0 for v spanning ker H;
- D4: H = 0 and the binary cubic T[κ, κ, κ]/6 has nonzero discriminant;
- X (other): anything else (cusp or worse: rank 1 with T[v, v, v] = 0, or H = 0 with zero discriminant).
Numerically: the degenerate set {det H = 0} is traced as the zero set of det H on a 2048 × 2048 grid of the torus (of [−1, 1]² for the control)
(sign changes between grid neighbours, refined by bisection along the grid edge to 1e−13); at each refined point the
fold quantity F(k) = T[v, v, v] with v the unit kernel vector of H (the eigenvector of the smaller-|·| eigenvalue) is
evaluated, normalised by ‖T‖ (operator norm estimate: max over 360 unit directions of |T[u, u, u]|). Points with
‖H‖ < 1e−6 are reported separately as Hessian-zero candidates and refined by Newton's method on H = 0 (three
equations in two unknowns, least squares).

## Criteria (fixed now)
For each phase, report: the number of Hessian-zero points found and their coordinates; their discriminants; the
minimum of |F|/‖T‖ over refined degenerate points at distance ≥ 0.05 from every Hessian-zero point (`minfold_far`), and
the minimum over all refined degenerate points (`minfold_all`), with the location of each minimum.
Classification verdict per phase:
- NFD4 (the GD hypothesis holds, numerically) iff every Hessian-zero point has |disc| / ‖T‖⁴ > 1e−6 and
  `minfold_far` > 1e−3, and `minfold_all` > 1e−3 (no near-cusp approaching a D4 point), and the CUSP test below
  finds no common zero;
- CUSP iff Newton's method on G = (det H, T[w, w, w]) = 0, with w = (q, −p) or (r, −q) for H = [[p, q], [q, r]]
  (the unnormalised kernel vector, the one of larger norm at the start point, kept fixed during the iteration; central
  finite-difference Jacobian, step 1e−7), started from every refined degenerate point with |F|/‖T‖ < 1e−2 and at
  distance ≥ 1e−3 from every Hessian-zero point, converges (both components below 1e−10 after division by ‖H‖² + ‖T‖³
  at the start point, within 50 steps) to a point at distance ≥ 1e−3 from every Hessian-zero point (reported with
  location; the grid spacing 2π/2048 ≈ 3e−3 means |F|/‖T‖ at grid-refined points cannot itself be below ~1e−3 near a
  simple zero of F, hence the Newton step);
- UNCLEAR otherwise (reported with the numbers).
Prediction made before the run (from the closed form, for the record): L and every Aσ have Hessian-zero points
exactly at (±π/2, ±π/2) (for Aσ: off-diagonal entries of H vanish only where u = a cos x + b cos y = 0 or a sine
vanishes, and H = 0 forces cos x = cos y = 0); L is NFD4 (its folds have T[e₁, e₁, e₁] = sin x = ±1); for Aσ no
prediction on cusps is made.
Control (must behave as stated, or the run is reported as NOT DISCRIMINATING): the phase
Ψ_ctl(x, y) = x²y + y² on [−1, 1]² (det H = 4(y − x²) changes sign across the parabola y = x², rank one there with
kernel (1, −x) and T[v, v, v] = −6x, so the origin is a point of type X and every other degenerate point a fold) must
be classified CUSP, with the X point found within 1e−6 of the origin. A grid on which det H does not change sign
(a touching zero) is outside what the method detects; the control is chosen so that this limitation is not what it
tests, and the limitation is stated with the result.

## Part B: the lattice-Laplacian kernel along the diagonal (fixed now)
Claim under test (draft statement T6L): with K(t, x) = ∫_{[−π, π]²} e^{i(t(cos k₁ + cos k₂) + x·k)} dk,
(−1)ⁿ n^{2/3} K(n, (n, n)) → c* = d4ClosedConstant(−1/48) = Γ(1/3)² · 48^{1/6} / √3 as n → ∞ (n ∈ ℕ). Derivation
(paper, for the record): the only critical point of cos k₁ + cos k₂ + k₁ + k₂ on the torus is (π/2, π/2), a D4 point
with phase value π and cubic part (κ₁³ + κ₂³)/6, disc = −27/36² = −1/48; the rest contributes O(n^{−1}). Independent
cross-check by a different route: K(n, (n, n)) = (2π)² (−1)ⁿ Jₙ(n)², and Jₙ(n) ~ Γ(1/3) / (2^{2/3} 3^{1/6} π n^{1/3})
(FOLKLORE, Watson's treatise §8.43), giving the same c* = 2^{2/3} Γ(1/3)² / 3^{1/3}.
Method: the box integral factorises into two 1D integrals ∫_{−π}^{π} e^{i(n cos s + n s)} ds; each is computed by the
trapezoid rule with P = 4n + 512 points (exact for trigonometric polynomials of degree < P; the integrand's Fourier
coefficients beyond degree n + 20 n^{1/3} are below 1e−16 by the Bessel tail, so P is ample), and once more with 2P
points as a quadrature check (|I_P − I_{2P}| < 1e−12 |I_P| required, else UNRESOLVED). n ∈ {10, 40, 160, 640, 2560}.
Criteria: (i) relative error |(−1)ⁿ n^{2/3} K − c*| / c* < 0.02 at n = 2560; (ii) the relative error decreases
monotonically over the five n; (iii) the imaginary part of (−1)ⁿ n^{2/3} K is below 1e−9 in absolute value for all n.
Control that must FAIL (i): the same quantity without the factor (−1)ⁿ, at n = 2559 (odd), must have relative error
> 1, otherwise the check is NOT DISCRIMINATING for the phase factor. Overall PASS iff (i)–(iii) hold and the control fails.
